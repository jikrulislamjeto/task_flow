# ✅ TaskFlow — Task Management App

TaskFlow is a simple, responsive, and interactive task management web application built with **HTML, CSS, and JavaScript**. It helps users organize daily tasks, track completed work, and stay productive through a clean and easy-to-use interface.

## 🌐 Live Demo

🚀 **[Visit TaskFlow](https://jikrulislamjeto.github.io/task_flow/)**

## 📸 Preview

![TaskFlow Screenshot](TaskFlow.png)

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔍 Search tasks
* 📌 Filter tasks by:

  * All
  * Active
  * Completed
* 🧹 Clear all completed tasks
* 📊 Display remaining task count
* 💾 Save tasks using LocalStorage
* 🎨 Smooth animations and interactive UI
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling, layout, responsive design, and animations
* **JavaScript (ES6+)** – Application logic and interactivity
* **DOM Manipulation** – Dynamic task management
* **LocalStorage** – Persistent task storage

## 📦 Dependencies

This project does not require any external libraries, frameworks, or npm packages.

It is built entirely with **Vanilla HTML, CSS, and JavaScript**.

The main goal of TaskFlow is to practice fundamental front-end web development concepts by building a functional task management application.

Through this project, the following concepts were practiced:

* Creating semantic HTML structures
* Designing responsive user interfaces with CSS
* Writing JavaScript logic for real-world interactions
* Manipulating the DOM dynamically
* Handling user input and events
* Using LocalStorage for client-side data persistence
* Implementing search and filtering functionality
* Deploying a website using GitHub Pages

### 1. Clone the repository

```bash
git clone https://github.com/jikrulislamjeto/task_flow.git
```

### 2. Navigate to the project folder

```bash
cd task_flow
```

### 3. Open the application

Open `index.html` in your preferred web browser.

No installation or additional setup is required.

## 💡 How It Works

1. Enter a task in the input field.
2. Click **Add Task** to create a new task.
3. Mark a task as completed when it is finished.
4. Use the **Search** box to find specific tasks.
5. Use **All, Active, or Completed** filters to organize your task list.
6. Delete individual tasks or clear all completed tasks.
7. Tasks are stored in **LocalStorage**, so they remain available after refreshing the page.
